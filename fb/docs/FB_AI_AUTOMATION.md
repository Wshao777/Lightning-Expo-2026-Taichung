OPER AI × Facebook 官方自動化架構

目的

本模組將：

Lightning-Expo-2026-Taichung
↓
OPER Core
↓
OPER AI
↓
Facebook Content Draft
↓
人工確認
↓
Meta 官方 API
↓
Facebook Page

串聯為一套內容發布流程。

核心原則

OPER AI 用於：

- 技術內容整理
- Markdown 文件轉換
- Facebook 文案生成
- 標題與摘要生成
- 多版本內容整理
- 發布前人工審核
- 合法的貼文發布
- 真實互動數據分析

OPER AI 不用於：

- 假帳號
- 灌讚
- 灌留言
- 假分享
- 虛假點擊
- 自動製造虛假觸及
- 繞過 Facebook 安全機制
- 未授權存取其他帳號
- 自動大量散播垃圾內容

內容來源

主要內容來源：

"Lightning-Expo-2026-Taichung"

內容經 OPER AI 整理後，預設狀態為：

"draft"

任何正式發布動作，都應經過使用者確認。

憑證安全

Facebook / Meta 憑證：

- 不得寫入 Python 原始碼
- 不得寫入 README
- 不得寫入 Markdown
- 不得提交到 GitHub
- 不得公開在 Issue
- 不得放入公開 ZIP

建議使用環境變數或本機安全設定。

流量原則

本專案追求：

「真實內容 → 真實讀者 → 真實互動」

而不是：

「程式 → 假帳號 → 假互動」

OPER AI 可以協助提高內容產出效率與發布效率，但不宣稱可以保證 Facebook 的自然觸及或演算法排名。

AI 內容所有權

OPER AI 只處理使用者授權提供的內容。

AI 不得擅自取得：

- 私人文件
- 未授權程式庫
- 私人帳號資料
- 密碼
- Cookie
- Session
- Access Token

開發者控制權

OPER Core 的架構、程式庫與授權範圍由 Wshao777 管理。

「可以串接」不等於「取得核心」。

「可以發布」不等於「取得程式庫所有權」。

「可以使用 API」不等於「取得 OPER Core」。

公開專案原則

公開 GitHub repository 只放：

- 程式碼
- 文件
- 範例設定
- 架構說明
- 安全政策

不得放入任何私人憑證。
