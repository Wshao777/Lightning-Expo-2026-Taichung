本專案可以使用 GPT / AI 作為：

- 程式設計輔助；
- 文件整理；
- 技術研究；
- 除錯；
- 測試；
- 架構討論。

AI 是工具，不是政府發證機關。

因此：

«GPT / AI 輔助開發，不等於取得政府證照。»

同樣：

«使用 GPT / AI，也不能單獨被解釋為抄襲或模型蒸餾。»

具體問題必須回到實際程式碼、資料來源及版本紀錄。

十、我們接受查核

本專案不要求社會大眾只相信作者自己的聲明。

歡迎依公開資料進行：

- 程式碼查核；
- Git history 查核；
- LICENSE 查核；
- 第三方授權查核；
- 證照查核；
- 氣象資料查核；
- 原始新聞來源查核。

如果發現資料錯誤，本專案將依可驗證資料進行修正。

十一、公開爆料的基本原則

本文件所稱「公開爆料」，不是指在沒有證據的情況下指控特定個人或機構。

本專案所要公開的是：

資料缺口、文件缺口、來源差異及需要查證的疑問。

因此：

«有證據就公開證據。»

«有官方資料就引用官方資料。»

«沒有證據就標示「待查證」。»

«不同意某項說法，不等於可以自行製造相反的事實。»

十二、關於新聞與官方說法

新聞報導、政府說明及本專案自己的主張，均應彼此區分。

本文件不宣稱任何尚未查證的陰謀論為事實。

同時，如果有人使用「氣候戰爭」、「仿冒」、「抄襲」、「無證照」等重大指控，也應提供足夠的原始資料供外界核對。

十三、最終公開立場

本專案的立場非常簡單：

«颱風是自然科學問題，先查氣象資料。»

«證照是文件問題，先查發證機關。»

«抄襲是著作權與來源問題，先查原始碼及版本紀錄。»

«AI 是技術工具，先查實際使用方式。»

«新聞是資訊來源，先查原始報導與證據。»

我們補齊 Repository 文件，就是為了讓這些問題可以被逐項查驗。

不刪歷史、不製造證據、不把政治標籤當科學證明。
