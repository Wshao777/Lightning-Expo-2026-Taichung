### 台灣民間開發者聲明

- 人類保留最終決策權
- AI 提供協調、分析與決策輔助

本聲明代表**開發者個人的民間觀點**，不代表台灣、中國、美國或任何政府、政黨、組織及全體人民的立場。

本專案希望促進台灣、中國與美國之間的和平對話、科技交流與民間合作。

對於任何涉及技術來源、資料使用、未經授權或其他爭議的事項，本專案將區分：

1. 已驗證的事實
2. 可追溯的證據
